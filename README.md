# 🔥 Free Fire Rewards API

An unofficial API service for Free Fire players to claim special rewards and bonuses.

## ✨ Features
- Reward distribution system
- Account verification
- Secure authentication
- Telegram notifications
- Free rewards for players

## 🚀 Quick Start

### Prerequisites
- Python 3.8+
- Flask
- Telegram Bot API (for notifications)

### Installation
```bash
# Clone repository
git clone https://github.com/yourusername/freefire-rewards.git

# Install dependencies
pip install -r requirements.txt

# Set up environment
cp .env.example .env
# Edit .env with your credentials

# Run server
python app.py
